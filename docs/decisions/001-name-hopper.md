# 001 — Call the game "Hopper"

**Decision** — The game and its page are named Hopper, with the line "Every bill needs a home."

**Why this came up** — The working name, Policy Sorter, described the mechanic but gave nobody a reason to click. The name sits on the poster, the browser tab and any post that links to the game, so a flat name costs attention everywhere.

**Options**
- **Hopper.** In the House, a member introduces a bill by dropping it into "the hopper", a wooden box by the clerk's desk. One short word, like the reference game Skyhold. Cost: most players won't know the term, so the page has to carry the meaning.
- **Refer Madness.** A pun on sending bills to committee. Funniest. Cost: it borrows a cannabis film title, which may not suit a public-radio audience.
- **Bill Drop.** Clearest. Cost: forgettable, and it sounds like many other games.

**What we chose and why** — Hopper (Tarik's call, from options Claude drafted). It's a real Capitol term, it's short enough to be a logo, and it could later name a mascot.

**What we gave up** — Instant clarity. The name only makes sense after the tagline or the page explains it.

**How we'll know if this was right** — In a playtest, ask five people what they think the game is about from the poster alone. If fewer than three connect it to Congress, the tagline needs to work harder.
